# Recursos visuales

Origen: `/home/isaac/Descargas/Figma/cliente/Cliente / 01 · Inicio.png` (1440 × 1640).

- `fiesta-hero.webp`: recorte original `(728, 188, 1318, 522)`, ilustración del banner, exportado sin pérdida.
- `fiesta-mix.webp`: recorte original `(88, 914, 344, 1106)`, ilustración de producto y etiqueta «Más vendido», exportado sin pérdida. El propio diseño repite esta ilustración para los cuatro productos.
- `dulcepack-mark.webp`: símbolo de la caja de dulces separado del nombre, con fondo transparente, recorte ajustado y reducción de tamaño sin pérdida visible para uso responsive.
- `dulcepack-wordmark.webp`: nombre gráfico «DulcePack» separado del símbolo, con fondo transparente y recorte independiente.

Los dos recursos de marca se derivaron de las imágenes proporcionadas por el usuario el 24 de noviembre de 2026. Se usaron las versiones sobre fondo claro y negro para delimitar el arte, retirar el fondo y conservar los bordes; los originales permanecen fuera del repositorio sin modificaciones.

No se alteraron los originales. Las exportaciones de Figma son PNG aplanados: no incluyen capas, SVG ni archivos de fuentes. Las fuentes Fredoka y Nunito se sirven localmente mediante los paquetes Fontsource (licencias incluidas en sus paquetes). Los iconos funcionales sencillos se dibujan como SVG inline. En móvil se reproduce con CSS el bloque morado de producto de la referencia.
